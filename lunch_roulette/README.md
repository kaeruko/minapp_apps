# 昼めしルーレット

みんアプ工房の公開アプリ。レトロな木目背景と画像素材の食べ物を円盤に配置し、抽選するアプリです。

## 使い方

- **ジャンル抽選**: 設定で選んだ料理ジャンルから等確率で抽選します。価格条件は適用しません（ジャンルに確かな店頭価格はないため）。
- **登録店抽選**: 自分で登録した店のうち、選択ジャンルに属し、価格目安が設定予算内の店を等確率で抽選します。候補がゼロの場合は明示的な案内を出し、ジャンル抽選へ自動切り替えしません。
- **店舗情報**: 店名、ジャンル、予算目安、地図検索用キーワード、メモを登録・削除。店舗情報の自動取得は行いません。
- **履歴**: 当選結果を最大500件、本人専用の`minapp.userState`に保存します。店舗を削除しても過去の履歴スナップショットは残ります。
- **食事の注意点**: 任意のNG食材メモを画面に表示できますが、店舗の原材料をAPIで取得・判定しません。注文前に店頭で確認してください。

抽選は`crypto.getRandomValues`の棄却サンプリングによる偏りのない整数選択を用います。アニメーションは見た目のみで、選択結果は保存API成功後に確定表示します。

## 保存・エラー処理

`lunch_roulette_v1`キーを`minapp.userState`に保存します。初回の`state_not_found`以外で自動データ初期化しません。データ形式や通信エラー時は編集を停止します。ブラウザの`localStorage`へ切り替えません。Runtimeの`minappready`イベントを待ち、タイムアウトで早まって停止しません。

地図検索ボタンはGoogleマップの検索URLを表示しますが、工房WebViewの外部ナビゲーション制限で開かない場合があります。検索ワードを画面にも表示しているのでコピーできます。実際の地図・近隣店舗取得は将来のプラットフォーム対応が必要です。

## 素材

すでにリポジトリ内にある`lunch_roulette_assets/lunch_roulette/*.png`のうち、利用する画像をGitのblob SHAで`lunch_roulette/assets/`へ再配置して配布します。生成元の大きいアセットシートは含めず、ZIPサイズ制限（2 MiB）内に収めます。

## 検証・公開

```sh
node --check lunch_roulette/roulette.js
node --check lunch_roulette/app.js
node lunch_roulette/test_roulette.js
python deploy/kobo/publish.py --app lunch_roulette --check
```

工房への自動公開は`.github/workflows/publish-kobo.yml`に追加されています。工房から起動して本人専用保存APIと絵柄の表示を確認してください。
