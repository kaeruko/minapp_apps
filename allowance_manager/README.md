# 小遣い管理

月の予算・カテゴリ別の支出・臨時入金（ATM）・履歴を管理するみんアプ工房向けWebアプリです。日付・金額・カテゴリ・メモを記録し、当月の残高と支出比率を表示します。未登録の予算や空の月にダミーデータを表示しません。

予算は全月共通、ATMによる入金は記録した月だけ使える額へ加算します。履歴は500件まで、削除前に確認が必要です。

保存は認証済み工房の `minapp.userState` のみを使い、他の保存場所へ自動切り替えしません。初回 `state_not_found` の場合だけ空の帳簿を作ります。形式不一致や通信障害では編集を停止します。

テスト: `node test_ledger.js` 。配布対象は `index.html`, `app.js`, `ledger.js`, `minapp-package.json` です。工房公開の設定については `../deploy/kobo/README.md` を参照してください。
